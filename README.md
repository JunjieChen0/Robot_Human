# Robot_Human

**人机交互课程作业 1：身体健康数据模型训练与交互评价**

基于公开的手机传感器数据识别日常活动，完成数据处理、模型比较、效果评价和交互原型设计，探索如何向用户提供清晰、易懂且不过度承诺的预测反馈。

> **当前进度：项目初始化与方案设计。** 当前仓库提供项目说明；数据处理脚本、模型、Streamlit 原型和实验报告将在后续阶段实现。本文中的模型与功能为实施计划，尚无训练指标或用户测试结果。

## 1. 任务与使用场景

| 项目 | 说明 |
| --- | --- |
| 预测任务 | 手机传感器日常活动识别，属于六分类任务 |
| 目标用户 | 普通大学生、健身者及关注日常活动的健康管理用户 |
| 使用场景 | 在课程演示中选择传感器窗口样例或上传特征 CSV，查看活动预测、类别概率与解释，并修改输入后重新预测 |
| 输入数据 | 一个时间窗口内的三轴身体加速度和三轴陀螺仪信号所提取的统计特征 |
| 输出结果 | 活动类别、各类别预测概率、关键输入及适用范围说明 |
| 原型形式 | 基于 Streamlit 的可操作网页原型 |

预测类别如下：

| 1 | `WALKING` | 行走 |
| 2 | `WALKING_UPSTAIRS` | 上楼 |
| 3 | `WALKING_DOWNSTAIRS` | 下楼 |
| 4 | `SITTING` | 坐姿 |
| 5 | `STANDING` | 站姿 |
| 6 | `LAYING` | 卧姿 |

## 2. 数据来源与说明

使用 **UCI Human Activity Recognition Using Smartphones（UCI HAR）** 数据集。

- [数据集主页](https://archive.ics.uci.edu/dataset/240/human+activity+recognition+using+smartphones)
- [官方下载链接](https://archive.ics.uci.edu/static/public/240/human+activity+recognition+using+smartphones.zip)
- [数据集 DOI](https://doi.org/10.24432/C54S4K)

| 数据项 | 说明 |
| --- | --- |
| 受试者数量 | 30 名志愿者，年龄为 19–48 岁 |
| 样本数量 | 10,299 个活动窗口；一个窗口为一个样本，并非一名用户 |
| 采集设备 | 腰部佩戴的 Samsung Galaxy S II 手机 |
| 传感器 | 三轴加速度计、三轴陀螺仪 |
| 采样频率 | 50 Hz |
| 窗口长度 | 2.56 秒，每个通道 128 个采样点 |
| 相邻窗口 | 50% 重叠 |
| 提供的数据 | 预处理后的窗口信号、561 维官方特征、活动标签及匿名受试者编号 |
| 官方划分 | 按受试者划分，70% 的受试者用于训练，30% 用于测试 |
| 缺失值 | 来源页面标注无缺失值；项目仍需通过代码核验并记录 |
| 数据许可 | UCI 页面标注为 CC BY 4.0；使用时保留来源和引用 |

本项目计划从提供的窗口信号重新提取简洁特征，不直接要求用户填写全部 561 维官方特征。

### 重要输入特征

| 信号 | 含义 | 单位 | 数据类型 |
| --- | --- | --- | --- |
| `body_acc_x/y/z` | 沿三个轴的身体运动加速度，重力分量已被分离 | g | 浮点数序列 |
| `body_gyro_x/y/z` | 绕三个轴的角速度 | rad/s | 浮点数序列 |
| `subject_id` | 匿名受试者编号，仅用于分组划分与分析 | 无 | 整数，不作为模型输入 |
| `activity` | 当前窗口的活动类别 | 无 | 整数标签，不作为模型输入 |

初始方案在六个信号通道上分别提取均值（mean）、标准差（std）和均方根（RMS），得到 **18 个数值特征**，单位与对应信号一致。均值反映平均水平，标准差反映变化程度，RMS 反映整体幅度。

仅使用身体加速度与角速度可能难以区分静态姿态；后续将根据验证集表现评估是否加入数据集中提供的总加速度等特征。最终特征集合及其选择依据将在报告中记录。

## 3. 数据处理与实验设计

### 数据检查与特征处理

1. 核验数据规模、标签范围及受试者编号。
2. 检查缺失值、非数值项和无穷值，记录数量及处理方式。
3. 检查重复窗口及特征重复情况，结合标签和受试者信息判断，不机械删除自然相似的活动窗口。
4. 检查异常值与特征分布，区分数据错误与真实的高强度动作，记录保留或处理的理由。
5. 提取窗口统计特征，保存特征名称、单位及计算规则。
6. 对需要缩放的模型使用标准化，并记录处理前后的变化。

### 训练、验证与测试划分

- 保留 UCI 官方按受试者划分的独立测试集。
- 从官方训练集的受试者中，按用户分组划出训练集和验证集。
- 同一受试者的窗口不会跨训练、验证、测试集合。
- 标准化、特征选择及其他需要拟合的预处理只使用训练数据。
- 验证集用于模型比较、特征选择与调参；记录划分编号、参数和随机种子以支持复现。
- 确定最终模型后再进行测试集评价，测试集不参与模型选择和参数调整。

### 模型比较

| 模型 | 作用 | 主要特点 |
| --- | --- | --- |
| 逻辑回归 | 线性基线 | 配合标准化，训练较快，可结合系数解释特征作用 |
| 随机森林 | 非线性对照 | 学习非线性关系，可提供全局特征重要性 |

计划以验证集宏平均 F1 为主要选择依据，结合各类别表现、推理效率和解释需求确定原型使用的模型。比较表将在实际运行后填写。

### 评价与错误分析

- 报告 Accuracy、宏平均 Precision、Recall、F1，以及各类别指标和样本数。
- 绘制混淆矩阵，分析易混淆的类别。
- 展示真实标签、预测标签、类别概率和关键特征，分析典型错误。
- 重点检查坐姿与站姿、行走与上下楼之间的混淆，具体结论以实验结果为准。
- 讨论受试者差异、窗口重叠、采集条件及类别覆盖对结果的影响。

## 4. 交互原型设计

```text
选择样例 / 上传特征 CSV
          ↓
检查必填字段、格式与数值
          ↓
展示预测类别与各类别概率
          ↓
查看输入、解释与适用范围
          ↓
修改输入 → 重新预测 → 比较结果
```

计划实现：

- **数据输入**：样例选择、CSV 模板下载和上传、特征编辑。
- **输入校验**：必填项、空值、列名、数值类型、无穷值和不合理范围提示；允许用户纠正输入。
- **结果展示**：预测活动、各类别概率和关键输入；超出训练参考范围时提示可靠性可能降低，参考范围不等同于医学正常范围。
- **解释反馈**：说明活动含义、输入特征可能的影响、常见混淆和模型限制；全局重要性不作为单次预测的因果解释。
- **修改与重试**：修改后重新预测，对比修改前后的类别和概率。
- **不确定性说明**：分类概率为模型估计，不保证经过校准，也不保证与实际正确率相等。

## 9. 适用范围与使用声明

本项目面向课程实验，数据来自特定年龄范围、腰部佩戴手机和规定活动下的采集。对其他手机放置位置、设备、年龄人群或未覆盖的活动，预测可靠性需要另行验证。单个活动窗口的分类不能直接推断全天运动量或个人健康水平。

**实验结果仅用于课程学习，不作为医学诊断、疾病筛查或治疗建议。** 使用公开数据和匿名测试记录，不收集姓名、学号等直接身份信息。
